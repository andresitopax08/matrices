## Descripción del Problema Resuelto

El objetivo de este proyecto es implementar un programa básico en Python que simula el proceso de cobro en un punto de venta o tienda comercial.

El sistema resuelve el problema común de calcular el monto total a pagar por un cliente al adquirir múltiples unidades de un mismo producto. Para lograr esto, se implementa una función personalizada que recibe el precio unitario y la cantidad de artículos, procesa la multiplicación correspondiente y retorna el subtotal.

---

## Estructura del Código

- **`calcular_total(precio, cantidad)`**: Función encargada de realizar el cálculo matemático ($precio \times cantidad$) y retornar el resultado.
- **Bloque Principal (`__name__ == "__main__"`)**: Maneja la interacción con el usuario mediante la consola, solicitando los datos de entrada (`input`), llamando a la función y formateando los resultados de salida.
